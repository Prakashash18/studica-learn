# ROS 2 on the Studica Robot: Step by Step

A slow, swipeable, mobile-friendly mini course for ITE students with no ROS background.

It starts at the command line, then covers the ROS idea, the workspace, packages, the Studica driver and topic tools, and ends with coding a sonar that stops a motor.

**Open the course:** https://prakashash18.github.io/studica-learn/

- 56 tiny steps, each followed by a quick check
- Swipe left/right (or use the buttons / arrow keys)
- Interactive cause-and-effect demos: typing terminal, `colcon build`, topic echo, sonar → motor simulator
- Progress is saved on the device

The whole course is a single `index.html` with no build step.
